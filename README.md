# Robust CIFAR-10 with 500 images

Train a small CNN (LeNet-style stem + 3 Inception modules + global average pooling, 88,754 parameters) from scratch on 400 CIFAR-10 images, validate on 100, and test on a clean and a corrupted ("shifted") test set.

## Files
| File | What it is |
|---|---|
| `robust-inception.ipynb` | The complete, executed notebook (Parts A–F, all plots and tables) |
| `results_summary.json`, `ablation_table.csv` | Numbers written by the last cell of the notebook |
| `README.md` | This file |

## How to reproduce
1. Python 3.10+ with: `torch`, `torchvision`, `numpy`, `pandas`, `matplotlib`, `scikit-learn`, `jupyter`.
   ```
   pip install torch torchvision numpy pandas matplotlib scikit-learn jupyter nbconvert
   ```
2. Open the notebook and run all cells, or from a terminal:
   ```
   jupyter nbconvert --to notebook --execute robust-inception.ipynb --output robust-inception-exec.ipynb --ExecutePreprocessor.timeout=-1
   ```
   CIFAR-10 is downloaded automatically by torchvision into `./data`. (If there is no internet, put `cifar_train.npz` and `cifar_test.npz` with arrays `x` (N×32×32×3, uint8) and `y` next to the notebook.)
3. Runtime is roughly 50–60 minutes on a 2-core CPU (about 60 training runs of at most 60 epochs; no GPU needed).

## Reproducibility
* Global seed 42 (data split and shifted-test generation); training seeds 0, 1, 2 (reported as mean ± std); hyper-parameter search uses separate seeds 100 and 101.
* Images are sorted by a hash of their pixels before sampling, so the 500 training images do not depend on file order.
* The shifted test set is generated by the notebook (seed 2026) following the task description, with an RGB channel swap as the hidden corruption. If you have the official file, save it as `shifted_test.npz` (`x` uint8 N×32×32×3, `y`) next to the notebook and it is used instead.
* The test sets are never used for any decision; all tuning uses the 100 validation images (and a shift proxy made only from them).
